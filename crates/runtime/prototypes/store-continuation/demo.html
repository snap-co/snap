Can a portable Rust workflow wait for host-owned storage?

This throwaway experiment runs the same async session-shaped workflow with a memory store and a scratch SQLite database. Read misses suspend, completed prefetches can avoid a read suspension, and writes check the authoritative record version.

These are recorded steps from actual Rust runs, not a JavaScript simulation or a live database. Password verification is omitted. The probe tests execution and storage ownership, not authentication.
